<!-- Project documentation for the devops-library-tests exercise. -->

This repository contains unit tests for the JavaScript utility library, with GitHub Actions and Coveralls coverage reporting.

Run `npm ci`, then `npm test` to execute the tests or `npm run test:coverage` to generate coverage.
